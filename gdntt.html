Danh sách các ID giả (Placeholder) để làm file Word mẫu

Anh/chị hãy copy các ID này vào file Word mẫu của mình. Khi xuất file, tool sẽ tự động thay thế bằng số liệu tương ứng.

  • {{TenDonVi}} - Tên đơn vị
  • {{NoiDungCongTac}} - Nội dung công tác
  • {{DiaDiem}} - Địa điểm
  • {{TuNgay}} - Từ ngày
  • {{DenNgay}} - Đến ngày
  • {{DanhSachNhanSu}} - Bảng danh sách nhân sự (dạng bảng)
  • {{DanhSachXe}} - Bảng danh sách xe (dạng bảng)
  • {{TongCTP}} - Tổng tiền công tác phí
  • {{TongNhienLieu}} - Tổng tiền nhiên liệu
  • {{TongCauDuong}} - Tổng tiền cầu đường
  • {{TongPhongNghi}} - Tổng tiền phòng nghỉ
  • {{TongCong}} - Tổng cộng tất cả

Lưu ý: Để xuất được file Word, anh/chị cần có sẵn file mẫu `.docx` đã được đặt các ID này. Hiện tại tôi chưa có file mẫu của anh/chị, nên nút "Xuất Word" sẽ tạm thời báo lỗi hoặc xuất file trắng. Chúng ta sẽ hoàn thiện phần này sau khi anh/chị gửi file mẫu.
